# System Diagrams

This folder contains the architecture and workflow diagrams for the AI Hospital Patient Management System.

## Diagrams

### System Architecture
Shows the overall architecture of the system, including patient input, n8n automation, workflow processing, AI services, external integrations, data storage, and system outputs.

### Workflow Interaction Diagram
Shows how the different hospital automation workflows interact with system components and external services.

### Event Flow Diagram
Shows how events move through triggers, n8n workflows, processing and decision nodes, external services, Google Sheets, notifications, and activity logging.

## Main Technologies Represented

- n8n
- OpenAI
- OCR.Space
- Google Sheets
- Google Calendar
- Gmail
- Webhooks
- Schedule Triggers
