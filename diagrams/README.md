# System Diagrams

This folder contains the architecture diagrams for the AI Hospital Patient Management System.

## System Architecture

The System Architecture diagram represents the overall structure and data flow of the project, including:

- Patient Input
- n8n Automation
- Hospital Workflows
- OpenAI and External Services
- Google Sheets
- Google Calendar
- Gmail
- OCR Processing
- Activity Logging
- System Outputs

The architecture demonstrates how n8n connects and automates the different components of the hospital patient management system.
